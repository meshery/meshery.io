Docker User:

Get mesheryctl

Install mesheryctl with Bash, Brew, Scoop, or download directly.

Use mesheryctl

Windows User:

Using Scoop

$ scoop bucket add mesheryctl https://github.com/meshery/scoop-bucket.git $ scoop install mesheryctl $ mesheryctl system start {% include copy-to-clipboard.html clipboard_target="#start-windows-scoop" clipboard_text="scoop bucket add mesheryctl https://github.com/meshery/scoop-bucket.git scoop install mesheryctl mesheryctl system start" %}

Using Binary

Not a Scoop user? Download and unzip the mesheryctl binary directly from the Meshery releases page. Add mesheryctl to your path for ease of use. Then, execute:

$ mesheryctl system start {% include copy-to-clipboard.html clipboard_target="#start-windows-binary" clipboard_text="mesheryctl system start" %}

Azure Kubernetes Service ( AKS ) User:

Get mesheryctl

Install mesheryctl with Bash, Brew, Scoop, or download directly.

Use mesheryctl

Authenticate to Azure and configure credentials for your intended AKS cluster using az aks get-credentials --resource-group <resource-group> --name <cluster-name>. Verify the active context using kubectl config current-context and select the intended context using kubectl config use-context <context-name> when necessary. Consult the official AKS setup instructions for more details.

mesheryctl system start -p kubernetes {% include copy-to-clipboard.html clipboard_target="#start-aks" clipboard_text="mesheryctl system start -p kubernetes" %}

Google Kubernetes Engine User:

Install mesheryctl with Bash, Brew, or Scoop, or download directly.

Using mesheryctl

Authenticate to Google Cloud and configure credentials for your intended GKE cluster using gcloud container clusters get-credentials <cluster-name> --location <region-or-zone>. Verify the active context using kubectl config current-context and select the intended context using kubectl config use-context <context-name> when necessary. Consult the official GKE cluster access instructions for more details.
