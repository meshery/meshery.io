patternInfo: |
  Carebound is a reference architecture for a healthcare application data plane.
  Patient-facing traffic enters through Gateway API. Clinical APIs run behind
  default-deny NetworkPolicies. Secrets are pulled from AWS Secrets Manager
  and never stored in Git. PostgreSQL is managed by CloudNativePG on an
  encrypted StorageClass. Kyverno enforces encryption labels and blocks
  privileged pods. OpenTelemetry Collector is the only path logs and traces
  take out of the clinical namespace.
patternCaveats: |
  This is a pattern, not a HIPAA authorization. You still need a BAA with
  your cloud provider, audit log retention, and workforce access reviews.
  Replace IRSA roles, the S3 WAL bucket, and placeholder images before apply.
  Do not put real PHI in this design.
